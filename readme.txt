Adicione código de rastreio dos Correios sem precisar abrir o pedido no WooCommerce.

== Description ==

Para adicionar o código de rastreio dos Correios você precisa abrir cada pedido e fazer isso. Com este plugin o processo de cadastrar vários códigos fica muito mais simples. Abra a lista de pedidos e adicione os códigos de rastreio sem abrir cada pedido.

O plugin WooCommerce Correios é necessário.

= Como funciona =

Na lista de pedidos, a coluna "Rastreio" mostra os códigos de cada pedido, com o link de rastreio. Digite o código no campo e clique em "Adicionar" (ou aperte Enter): o código é salvo no pedido, entra uma nota e a cliente recebe o e-mail de rastreio do WooCommerce Correios, como se o código fosse adicionado no pedido aberto. Para tirar um código, clique no × ao lado dele.

Funciona na lista de pedidos com e sem HPOS (armazenamento de pedidos de alto desempenho do WooCommerce) e também no celular. A coluna aparece para quem pode editar pedidos.

== Installation ==

- Envie os arquivos do plugin para a pasta wp-content/plugins, ou instale usando o instalador de plugins do WordPress.
- Ative o plugin.

= Requerimentos: =

É necessário instalar o plugin WooCommerce Correios
